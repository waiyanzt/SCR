# `kg-datasets/` — Evaluation datasets

This directory holds the evaluation datasets. They are **not bundled** in the
repository — download them from the Google Drive link in the top-level
[README](../README.md#data-acquisition) and place the folders here:

```
kg-datasets/
├── fb15k237/
├── wn18rr/
├── codex-m/
├── grail/
├── ingram/
├── FoundationGraphKG/
└── FoundationNodeKG/
```

You can also point `dataset.root` in `config/eval_all.yaml` to a custom location.
